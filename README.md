# 🚀 CodeAlpha Artificial Intelligence Internship

This repository contains the projects I completed during the **CodeAlpha Artificial Intelligence Internship**. These projects demonstrate practical applications of Artificial Intelligence, Machine Learning, Natural Language Processing (NLP), and Computer Vision using Python and modern AI frameworks.

---

## 📂 Projects

### 🌐 Task 1 – Language Translation Tool

A multilingual language translation application that allows users to translate text between different languages using a translation API.

#### Features
- User-friendly interface
- Source and target language selection
- Real-time text translation
- Clean and responsive UI

#### Technologies
- Python
- Flask
- Google Translate API
- HTML
- CSS

---

### 💬 Task 2 – FAQ Chatbot

An AI-powered chatbot that answers user questions by matching them with the most relevant FAQ using Natural Language Processing techniques.

#### Features
- NLP text preprocessing
- Tokenization
- Stopword removal
- TF-IDF Vectorization
- Cosine Similarity
- Interactive chatbot interface

#### Technologies
- Python
- Flask
- NLTK
- Scikit-learn
- HTML
- CSS

---

### 👁️ Task 4 – Object Detection & Tracking

A real-time computer vision application that detects and tracks multiple objects using a webcam.

#### Features
- Real-time webcam detection
- Multi-object detection
- Object tracking with unique IDs
- Bounding boxes and labels
- YOLOv8-based object detection

#### Technologies
- Python
- OpenCV
- YOLOv8
- Ultralytics
